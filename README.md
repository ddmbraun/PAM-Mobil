# PAM Mobil

Mobile Web-App zur Auftragserfassung auf der Baustelle. Läuft als PWA im Browser,
lässt sich auf dem Startbildschirm installieren und arbeitet auch offline weiter.

Die App speichert keine Daten in diesem Projekt. Alle Inhalte liegen im
Google-Drive-Konto der anmeldenden Person und werden erst nach deren Anmeldung
geladen — ohne Anmeldung startet die App leer.

Gegenstück am Rechner: PAM Desktop.
